Bajnok–Beatty Conjectures 4.1 and 1.6 (arXiv:2406.04045v1, Section 4, p. 10; Section 1, p. 3): classification and extremal noncyclic order

Haobo Ma, Wenlin Zhang

论文

一个有限的位置系统若只有两种可正反执行的移动，在规定步数内最多能覆盖多少位置？Haobo Ma 和 Wenlin Zhang 完整判定了一类交换群何时满足要求，并确定所有非循环有限交换群中的最大规模，解决了 Bajnok 和 Beatty 的两个猜想。

群表示位置，加法表示移动；交换性意味着移动次序无关，循环性指某一种移动本身就能遍历全部位置。两个不同元素 a、b 若能把每个位置写成 xa + yb，且 |x| + |y| ≤ s，就构成半径 s 的带符号生成对，负系数表示反向移动。这等价于相应无向移动图的直径不超过 s，研究的是系统规模与最远行程之间的关系。

第一类群由模 2 和模 2k 的余数组成，共有 4k 个位置。作者对正整数 k、s 证明：s 为奇数时，存在生成对当且仅当 2k ≤ s² − 1；s 为偶数时，2k ≤ s² − s 总能实现，2k > s² 则不可能。在中间区间，s 被四整除时要求 k 为偶数，否则要求 k 除以四余二。规模上界和较低区间此前已由 Bajnok、Beatty 证明，新补全的是偶数半径的上端区间。

证明转而研究整数系数对。到达同一位置的系数对之差组成周期性网格，称为关系格。生成条件意味着菱形 |x| + |y| ≤ s 沿此格平移后覆盖全部整数点。沿用 Dougherty、Faber 的格方法，作者变换坐标，把菱形化成正方形。群的奇偶结构使边长为 s 的整数正方形必须代表变换后格的全部 2k 个类，从而得到 2k ≤ s²。

关键在于接近等号时的刚性。如果正方形的点数比类数多出不到 s，作者证明，某个格基的两个偏移量之积必须等于这一差额。写成 s = 2t、k = 2t² − r，其中 0 ≤ r < t，奇偶性迫使 r 为偶数；t 为奇数时，r 还须被四整除。反过来，明确构造的关系格既给出所需群，又保证每类都能在限定步数内到达。因此这些算术条件不仅排除不可能情形，也保证其余情形存在。

对更广泛的问题，记 N(s) 为具有这种生成对的非循环有限交换群的最大阶。作者证明，s ≥ 3 时，若 2s + 1 为素数，则 N(s) = 2s²；否则 N(s) = 2s² + 2s − (p² − 1)/2，其中 p 是它的最小素因子。每个候选群都由模 c 与模 ck 的余数组成，c ≥ 2。关系保持系数模 c 的余数，因此 c² 个余数类各须包含至少 k 个菱形点。计算稀疏类即可限制群阶；只有 c 整除 2s + 1 的特殊对齐才可能超过 2s²。达到上界的构造归功于 Bajnok、Beatty；这里的论证取消了此前对生成对形式的限制。另外，N(2) = 9，半径一没有非循环例子。

完美生成对要求每个位置恰好对应一个允许的系数对。作者证明其群必为循环群，却未解决关于生成对形状的完整分类。模 13 的 {2,10} 是半径二的完美例子：零、单次、重复及混合移动给出十三个不同余数。它等于 {2,3} 的五倍，却不等于零至四中任何倍数。因此原猜想印出的乘数范围须改为实际群阶模数下的可逆余数；修正范围不等于证明余下断言。

文稿给出了书面证明。所报告的 Lean 证据覆盖第一类群的完整分类、近正方形格的刚性、上端区间的必要同余条件及充分构造族，不单独陈述全局最大值或完美生成对结论。报告的穷举检查覆盖 k 至 40 的第一类群并比较至半径 12，另对阶不超过 61 的所有非循环二生成交换群检查半径二至五。这些有限检查仅补充无限参数的证明。本文揭示接近最大规模的双移动系统背后的算术刚性；修正后的完美生成对分类，以及三个或更多生成元的精确阶问题，不属于本文已建立的结论。
